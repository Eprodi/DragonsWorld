# Dragon Isles

Um projeto de fã, independente e sem vínculo com os criadores ou distribuidores de *Dragons World*. A ideia é construir um jogo original de criação e coleção de dragões, inspirado no gênero e nas lembranças dos jogadores. Não use recursos, código, nomes de personagens ou materiais proprietários do jogo original.

## Protótipo atual

Abra `index.html` em um navegador moderno. O protótipo permite alimentar o dragão, coletar moedas, cuidar do habitat e chocar um ovo. O progresso fica salvo neste navegador.

## Próximas etapas

- Criar mais dragões e habitats com identidades visuais próprias.
- Adicionar criação e descoberta de combinações elementais.
- Planejar progressão, missões e economia do jogo.
- Melhorar acessibilidade, animações e suporte a dispositivos móveis.

## Desenvolvimento

O protótipo usa HTML, CSS e JavaScript sem dependências ou etapa de compilação. Sirva esta pasta com qualquer servidor estático local, ou abra `index.html` diretamente.

## Aviso

Este é um projeto de fã não oficial. *Dragons World* e quaisquer marcas relacionadas pertencem aos seus respectivos titulares. Este repositório não inclui nem pretende distribuir ativos do jogo descontinuado.
