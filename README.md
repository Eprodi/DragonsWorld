# DragonsWorld

Projeto de fã independente, inspirado no gênero de criação e coleção de dragões. Não tem vínculo com os criadores ou distribuidores de *Dragons World* e não inclui código, nomes de personagens ou materiais proprietários do jogo original.

## Protótipo jogável

Abra `index.html` em um navegador moderno. O ciclo inicial inclui alimentar dragões para ganhar experiência, coletar moedas do habitat, comprar frutas e chocar ovos. O progresso fica salvo no armazenamento local do navegador.

Por enquanto, o jogo tem apenas quatro elementos: Fogo, Água, Terra e Ar. O ovo revela aleatoriamente um dragão de um desses elementos. A coleção permite selecionar qual dragão fica no habitat.

## Desenvolvimento

O protótipo usa HTML, CSS e JavaScript sem dependências ou etapa de compilação. Sirva esta pasta com qualquer servidor estático local, ou abra `index.html` diretamente.
