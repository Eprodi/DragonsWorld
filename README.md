# DragonsWorld

Projeto de fã independente inspirado em *Dragons World*. Não tem vínculo com os criadores ou distribuidores do jogo original e não inclui recursos proprietários.

## Protótipo jogável

Abra `index.html` em um navegador moderno com conexão à internet. A cena 3D usa Three.js carregado por CDN. Arraste para girar a câmera e use a roda do mouse para aproximar ou afastar.

O ciclo atual começa com uma ilha ocupada por árvores e pedras. Ative **Limpar terreno** e toque nos obstáculos: removê-los consome moedas e concede XP. Colete moedas dos habitats, compre novas ilhas e limpe seus terrenos. Também é possível alimentar o dragão e comprar frutas. O progresso fica salvo neste navegador.

O protótipo está limitado aos quatro elementos combinados para esta fase: Fogo, Água, Terra e Ar.

## Próximas etapas

- Criar uma reprodução mais específica dos habitats e modelos de dragões com arte original.
- Implementar reprodução e cruzamentos entre os quatro elementos.
- Expandir missões, economia e seleção das ilhas compradas.

## Desenvolvimento

Feito com HTML, CSS e JavaScript. Não requer instalação, mas precisa de conexão com a internet para carregar o Three.js.
