# DragonsWorld

Projeto de fã independente, inspirado no jogo de criação e coleção de dragões *Dragons World*. Não tem vínculo com os criadores ou distribuidores do original e não inclui recursos proprietários.

## Protótipo

Abra `index.html` em um navegador moderno com conexão à internet. A cena 3D usa Three.js carregado por CDN. Arraste sobre a ilha para girar a câmera e use a roda do mouse para aproximar ou afastar.

O primeiro ciclo permite alimentar dragões para ganhar experiência, coletar moedas do habitat, comprar frutas e chocar ovos. O progresso fica salvo neste navegador. Por enquanto, há apenas quatro elementos: Fogo, Água, Terra e Ar.

## Próximas etapas

- Refinar a ilha, os habitats e as criaturas com arte original.
- Adicionar reprodução de dragões e combinações entre os quatro elementos.
- Planejar missões, economia e novas ilhas.

## Desenvolvimento

O protótipo é feito com HTML, CSS e JavaScript. Não requer instalação, mas precisa de conexão com a internet para carregar o Three.js.
